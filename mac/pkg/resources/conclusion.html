VibeHub is installed

It just opened, and asks for a tracker token the first time it runs.

Mint one on the web under Settings → Tracker and paste it in. No installer carries your token — not this one, not the one-command version. You type it once, in the app.

A vibehub-tracker command was also installed in your own ~/.local/bin — optional, for counting Cursor and Windsurf turns. If your shell cannot find it, add that directory to your PATH and reopen the terminal:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
zsh, the macOS default. If your terminal runs bash, use ~/.bash_profile instead — a login bash never reads ~/.bashrc.

It belongs to you, not to root. Dragging VibeHub to the Trash removes it as well: the next time it runs it sees the app is gone and deletes itself, with no password needed.
