Scroll-to-top on route change

✓ done

Plan: "ScrollToTop on pathname change (PUSH/REPLACE only, never POP — back/forward keeps position), mounted once in App; /u/a → /u/b counts"

What changed

  • New ScrollToTop component mounted once inside the router in App. On every pathname change it calls window.scrollTo({ top: 0, behavior: "auto" }).
  • useNavigationType() === "POP" returns early, so browser back/forward restores where you were — only PUSH and REPLACE reset the offset.
  • Fixes the PO's ask directly: opening someone's profile from the bottom of a long Home feed used to land you mid-page.
